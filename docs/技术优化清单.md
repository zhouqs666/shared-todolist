# 技术优化清单（存档）

> 以下问题来自 2026-08-08 的全栈代码审查，按优先级排列。本文档仅作记录，供后续逐条处理。
> 视觉/交互体验的优化另见其他分析。

---

## 🔴 高优先级

### 1. 软删除是半成品 —— 回收站只能进不能出
- 删除已改为软删除（标 `deleted_at`），但**无恢复功能、无 30 天物理清理任务、无回收站 UI**
- 用户删了就找不回来（AGENTS.md:96 自己标注"待实现"）
- 附带 bug：软删除的 todo 仍带 reactions，`listReactions`（db.js:312）不过滤 `todo.deleted_at`，产生孤立数据
- **位置**：`supabase/migration-soft-delete.sql`、`public/js/db.js`、`public/js/app.js`

### 2. Service Worker 缓存版本与发布版本脱钩
- `sw.js:15` 的 `VERSION = 'v2'` 硬编码，`release.mjs` 从不改它
- 浏览器 PWA 端发若干次热更新后，用户仍可能拿到旧缓存 JS（`/js/*.js` 是缓存优先策略 sw.js:91-102）
- **位置**：`public/sw.js:15`、`scripts/release.mjs`

### 3. 缺 `VIBRATE` 权限
- 代码多处调 `navigator.vibrate()`（app.js:543/851/1358），`notify.js:90` 创建通知渠道声明震动
- 但 `AndroidManifest.xml` 没声明 `android.permission.VIBRATE`
- **位置**：`android/app/src/main/AndroidManifest.xml`

### 4. 热更新健壮性缺口
- 无 checksum 校验（update.js:114），签名 URL 只防越权不防篡改
- 签名 URL 仅 60s 有效（update.js:107），慢网络易超时
- 无失败重试，本次失败就放弃
- SplashScreen reload 无超时兜底（update.js:123-133）
- **位置**：`public/js/update.js`

## 🟡 中优先级

### 5. 事件监听器 / 定时器泄漏（架构性）
- `initRealtime`（realtime.js:95）和 `initPresence`（realtime.js:293）返回了 `unsubscribe`，但 app.js:173/226 调用时**没保存返回值**，清理函数从未被调用
- `messages.js:83` 的 ESC 监听器是匿名箭头函数，**永远无法 removeEventListener**
- `notify.js:160` 的 Capacitor `appStateChange` listener 无清理
- `app.js:204/236` 两个 `setInterval` 无清理
- 单页固定账号下影响小，但热更新 reload 时会短暂叠加

### 6. 字段转换函数双份维护
- `toExternal`/`toNote`/`toReaction`/`toSticker` 在 `realtime.js:21-75` 和 `db.js:17-33` 各写一份
- realtime.js 自己注释了"与 db.js 同步"，加字段极易漏改
- 应抽到独立模块导出

### 7. 大量死代码：主题系统 + FX 开关
- `style.css:64-95` 定义 5 套主题，但 `theme.js` 全 no-op 永远返回 `'mint'`，`index.html:19` 写死 `data-theme='mint'`
- pink/blue/sunset/dark 四套主题变量（约 30 行）永不生效
- `theme.js:12` 的 `fxEnabled` 硬编码 true，所有 `if (!isFxEnabled()) return` 判断是死代码（app.js:1649/1728、blindbox.js:162）

### 8. `app.js` 1773 行单文件过长
- 一个文件塞了渲染 + 业务 + 动画 + 通知 + 纪念日 + lightbox + action sheet + 退出确认
- 建议按职责拆分

### 9. 重复实现
- `toast.js` 与 `messages.js:336 toastSimple` 两份几乎相同的 Toast
- `app.js:1209 NUDGE_SVG` 与 `app.js:1382 ICONS.ask` 完全相同的 SVG
- `realtime.js:131-138` 和 `175-182` 隐藏款揭晓逻辑重复两遍

### 10. 外键级联规则不全
- `todos.created_by/completed_by`、`daily_notes.author_id/read_by`、`reactions.user_id`、`stickers.unlocked_by` 引用 auth.users 都**无 ON DELETE 规则**
- 删账号会失败或留孤儿。只有 `nudge_by` 显式 SET NULL（schema.sql:59）
