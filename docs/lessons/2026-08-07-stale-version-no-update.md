# 2026-08-07：版本号低于线上，App 判定「无更新」

**关联规则**：AGENTS.md 铁律三（版本号必须比线上高）

## 发生了什么

没查线上版本直接发布 2.0.1，但线上已经是 2.2.4。客户端判定更新是「服务端版本 ≤ 本地版本 →
无更新」，于是 App 连开几次都没有任何变化 —— 用户侧看起来就是「改了没生效」。

## 根因

1. 发布前没有查线上最新版本号，拍了脑袋。
2. `index.html` 里的 meta 不是权威（发布后才会被同步/滞后），拿它当依据必错。

## 修复与防回归（现在落地在 AGENTS.md 铁律三）

- 发布前必查：`node scripts/query-latest-version.mjs`（只读，打印 enabled 最新 + 历史最高两个口径）
- `release.mjs` 内置 `assertNewerThanLatest()`，版本号不够高直接拒绝发布 —— 不靠记忆
- **2026-09-16 收紧**：新版本必须语义化大于「**历史上出现过的最高版本**」，不只是 enabled 的最新。
  已下线的版本号也算「用过」—— 设备本地版本可能是某个曾下发、后来被下线的版本
  （回滚演练留下的 2.7.65 就是这种行，只跟 enabled 行比会放行它，那批设备永远收不到更新）
