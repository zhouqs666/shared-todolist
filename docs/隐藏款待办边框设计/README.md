## 为什么留档（别删）

这轮探索定下了两条沿用至今的判断，值得留证据：

1. **"一眼可辨"要靠材质，不只是色相**：当时的结论是「稀有=缎面、史诗=珠光、传说=鎏金」，
   最终实现沿用了这个分层思路，只是把"光斑数量"换成了"工艺"（见 `F-08` 的否决记录）。
2. **不做缩放式呼吸**：图里"呼吸光晕"的示意后来实测被否 —— 卡片是扁矩形，缩放会让光雾
   左右撑开、上下不动（详见 `F-08`「呼吸的实现约束」）。
