# 2026-07-31：谓词批量删清空生产 todos，用户数据永久丢失

**关联规则**：AGENTS.md 铁律一（最高铁律）

## 发生了什么

为了验证「空状态 UI」，对**生产库**执行了 `supabase.from('todos').delete().neq(...)` —— 一个
「删全部」形状的谓词批量删除。用户的全部待办被永久删除；项目当时在 Supabase Free 套餐，
没有备份，**无法恢复**。

## 根因

1. 把「验证一下」当成了动生产库的理由 —— 写操作的判据（产品功能 vs 验证）当时不存在。
2. 删除用的是谓词批量形状（`.neq()`），没有任何 id 清单、没有备份、没有 dry-run。
3. Free 套餐无时间点恢复，删了就是真没了。

## 修复与防回归（现在落地在 AGENTS.md 铁律一）

- 铁律一成立，列为最高铁律；判据一句话：「这个写操作是产品功能的一部分，还是为了验证一下？」
- 测试用隔离测试数据（打标记、验证完只删带标记的）；模拟器/真机用独立测试账号或测试项目
- 删除前必须备份（`scripts/backup-tables.mjs`，只读导出、完整行、可恢复）
- 谓词批量删除绝对禁止，必须显式 id 列表
- 后续补齐的物理隔离与只读守卫见 [2026-09-14-web-channel-isolation.md](2026-09-14-web-channel-isolation.md)
