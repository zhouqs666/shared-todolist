DESIGN DECISIONS · 关键判断

3 个关键取舍

#6 双栏布局怎么处理？
移动端坚持单列纵深 + 双主角镜像，iPhone SE 单栏仅剩 85pt，无法承载信息单元；平板及以上才激活真双栏。
FAB 是怎样的交互？
长按 400ms 展开「心意菜单」，4 片花瓣围绕旋转展开：写信 / 留语音 / 拍照 / 共享此刻。
双主角如何视觉对称？
身份徽章 + 卡片角色条：小宝宝 = rose-500 桃形；大宝贝 = ink-500 方印；让对称落在身份识别系统而非布局。
