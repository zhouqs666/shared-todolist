## 1. 背景与目标

惊喜预算从「完成时」挪到「开出时」（D1）：开出是收集玩法唯一产生新事物的时刻（贴纸解锁在此），
高光全部前置到这里；完成时刻所有待办一律平等。

目标（业主原话转译）：

- **质感极佳**：卡片精美、有工艺质感（金箔/幻彩/纸纹），不是"弹个 div"
- **激动人心**：揭晓瞬间有爆发力（原神祈愿级的仪式感）
- **上瘾惊喜感**：悬念前置信号 → 顿帧 → 爆发 → 展示的完整多巴胺曲线
- **循环动效**：卡面图案/流光持续循环，可反复把玩

## 2. 总体架构

```
reveal-card（一个组件，三个入口）
├─ DOM 遮罩层        overlay：遮罩 + 关闭 + 跳过交互
├─ 卡片层（DOM/CSS） 卡背 / 卡面：材质分层全部代码绘制，零图片资产
│   ├─ 卡框层        档位金属渐变（RARITY_META.colors 单一来源）
│   ├─ 纸纹层        SVG feTurbulence 噪点 data-uri（零资产）
│   ├─ 内容层        贴纸 SVG（RARITY_META.stickerIcons 真图标）+ 名称/档位/册进度/NEW
│   ├─ CSS 流光层    斜向 sheen 扫过循环（WebGL 不可用时的兜底流光）
│   └─ WebGL holo 层 单四边形 fragment shader（epic/legendary only）
├─ 粒子层（canvas）  渗出（悬念）/ 爆发（揭晓）/ 环境星芒（idle），自写轻量粒子池
├─ 光束层            悬念段背景旋转光柱（repeating-conic-gradient）
└─ 控制器            分镜时间轴（可跳过）/ 降级闸门 / 陀螺仪·pointer tilt
```

**单一来源约束**：配色、贴纸图标、名称、档位文案全部取自 `blindbox.js` 的 `RARITY_META` /
`SERIES_DEFS`（与现有卡片、图鉴、toast 同源），组件内**不得**出现第二份参数。
`style-lab.html` 工作台后续增加「开出卡片」小节（项目惯例：改档位视觉参数回工作台）。

## 3. 技术选型（方案 B 详述）

| 候选 | 结论 | 理由 |
|---|---|---|
| A 纯 CSS/SVG | **基座**（全档使用） | 材质/卡框/纸纹/基础流光；pokemon-cards-css 一类 demo 证明 blend-mode + 跟手可到"手感极佳" |
| B 手写 WebGL shader | **采用**（epic/legendary） | 真·全息折射（法线扰动 + 虹彩 + 跟手 glare）是"质感上限"所在；**单四边形 + fragment shader 约 200 行 JS，无需任何库**；capability 检测失败回落 A |
| C Lottie/Rive | 否 | 运行时 200~250KB + 需 AE/Rive 资产生产线，与"无构建、零依赖、AI 工作流"冲突 |
| D 预渲染视频 | 暂否 | 保真最高但热更 zip 膨胀（每档数百 KB~MB）、无法跟手、跳过生硬；通道 A 体积敏感。CSS/WebGL 上限不满意再议 |

引入新技术的边界：**只加"手写 shader + 自写粒子"这类零依赖代码**，不引入运行时库；
这是热更体积（`release.mjs` 通道 A）与 Android WebView 兼容性（弱 GPU 回落）共同决定的。

## 4. 揭晓分镜（时间轴）

### 4.1 本端开出 · legendary（原神感全套，总时长约 4s）

```
0.00s  待办正常入列（列表层不受影响，卡片叠加在列表之上）
0.30s  遮罩淡入 + 背景光柱启动；卡背自下方飞入居中（fly-in + 轻旋转）
0.55s  悬念段：卡背呼吸脉动 + 【前置信号】金色粒子自卡缝渗出（节奏渐强）
       —— 对应原神"金光"，在揭晓前 1 秒告诉用户档位，这是上瘾感的核心
1.60s  顿帧 180ms（一切静止，屏息）
1.80s  揭晓：白闪 200ms → 翻面（rotateY 180° + squash&stretch 弹性）
       → 粒子爆发（复用 canvas-confetti 配色语义）→ 屏幕轻震 320ms → 分档震动
2.40s  展示 idle：金箔流光循环（WebGL）+ 跟手/陀螺仪倾斜
       + 名称/册进度/NEW 角标逐行浮现 + 环境星芒低频闪烁
关闭   ✕ / 点遮罩 / ESC → 卡片飞向图鉴入口方向缩小消失（"回家"瞬间，强化收集）
```

### 4.2 epic / rare 的落差（分级仪式感 = 稀有感来源）

| 档位 | 悬念段 | 揭晓 | idle 流光 | 总时长 |
|---|---|---|---|---|
| rare | **无**（无前置信号，直出） | 无白闪/屏震，轻翻面 + 少量樱粉粒子 | CSS sheen（无 WebGL） | ~1s |
| epic | 玫紫粒子渗出，节奏轻 | 白闪较弱 + 翻面 + 紫系爆发 | WebGL 幻彩 holo | ~2.5s |
| legendary | 金光渗出渐强 + 光柱 | 全套（白闪/屏震/弹性翻面） | WebGL 金箔 holo | ~4s |

- **任意时刻点按 = 快进到展示段**（尊重高频用户；默认节奏即精心调校，不设自动关闭）
- 通知模式（D7-②）：无悬念段、无爆发，卡片淡入即 idle，角标「ta 开出的」，无撒花

## 5. 卡背方案（D6 待业主确认的形态项）

卡背在三档通用（**档位中性**——前置信号由渗出粒子颜色承载，卡背不剧透，原神同思路）。
候选三案：

### 案 C「缎纹卡背」（推荐，原型已实现）
深李紫夜色底 + 金色双线内框 + 中央金色爱心纹章（双环护边）+ 四角金线回纹 + 缓速斜向 sheen。
理由：① TCG 卡背的"收藏物"语义最强，原神感需要一张"像卡"的背；② 爱心纹章延续品牌情感语言
（有爱 = 爱心），不是通用抽卡皮；③ 深底与金色渗出粒子的对比度最高，前置信号最醒目。

### 案 A「礼盒」
卡背绘制盲盒礼盒 + 缎带蝴蝶结（金色线描），呼应"盲盒"心智。优点：隐喻直白；
缺点：具象插画在 280px 卡面上容易显得"可爱"多于"珍贵"，与原神感有张力。

### 案 B「问号星幕」
经典抽卡问号 + 星幕粒子底。优点：全人类秒懂；缺点：最像通用抽卡皮，品牌感最弱，
且与现有"藏款"的含蓄气质略冲。

> 定案后此节收敛为一句话 + 截图。三案均只影响 `.face.back` 一层，切换成本≈0。

## 6. WebGL holo shader 设计

- 结构：一个全屏四边形（卡片裁剪由容器 `border-radius + overflow:hidden` 承担），
  fragment shader 约 60 行；**无库**，直接 `getContext('webgl')` 手写
- Uniform：`u_time`（流光循环）、`u_tilt`（vec2，陀螺仪/pointer 归一化 -1..1）、`u_res`
- 效果构成（legendary 金箔）：
  1. 值噪声（procedural，零纹理）扰动斜向金带 → 随 tilt 与 time 流动
  2. 虹彩：`cos` 调色盘在金基调上低权重混色（幻彩不过艳）
  3. 闪点：hash 网格随机 glint，随时间闪烁（金箔颗粒感）
  4. 跟手 glare：高光中心 = f(u_tilt)，晃手机时流光+高光同步跟动（D5）
  5. 输出低 alpha，经 `mix-blend-mode: screen` 叠在 CSS 材质上——shader 只负责"光"，
     纸纹/卡框/文字仍是 CSS，保证任何 DPI 锐利
- epic 幻彩：同一 shader 换调色盘 uniform（紫玫基调），不复制第二份
- 兜底：`getContext('webgl')` 失败 → 移除 canvas，CSS sheen 层本来就是循环流光，视觉降级平滑

## 7. 跟手倾斜与陀螺仪（D5）

- 数据源：`deviceorientation`（beta/gamma）；首次读数记基线（握持姿态 = 零点），
  此后 tilt = clamp((γ-γ₀)/25°) 等；桌面 / 无陀螺仪 → pointermove 覆盖同一 tilt 状态
- iOS 13+ 需手势授权：检测 `DeviceOrientationEvent.requestPermission` 存在时出「启用陀螺仪」按钮
- tilt 消费方三处同步：① 卡片 3D 倾斜（rotateX/Y ≤ 10°，加在独立 tilt 层，与翻面动画分层不打架）
  ② CSS 变量 `--gx/--gy`（sheen 高光位置）③ shader `u_tilt`
- 松手/静置：tilt 缓动回零（弹簧感），不做生硬回弹

## 8. 音效决策（D4）

**无音效**：不实现 riser/stinger，现有 `playDing` 不进卡片流程。保留震动
（`navigator.vibrate` 分档 pattern，legendary `[30,25,90]` 级别；fx 关 / reduced-motion 时跳过）。

## 9. 降级链与闸门

```
全效（WebGL + 粒子 + 光柱 + 屏震 + 震动）
 ├─ WebGL 不可用      → 移除 holo canvas，CSS sheen 流光兜底（视觉几乎无损）
 ├─ 特效开关关闭       → 静态精卡（材质/文字/进度全保留，无粒子/光柱/屏震/循环动效）
 ├─ prefers-reduced-motion → 同上（入口 media query + JS 双判）
 └─ 极端（都不可用）   → 现有 toast 文案（D8 降级通道，代码不删）
```

## 10. 性能与体积预算

- 粒子/循环动效全部走 transform/opacity；rAF 循环仅在 overlay 打开时运行，
  `document.hidden` 暂停；遮罩关闭即停止渲染
- 新增体积：shader + 控制器 + 粒子 ≈ **6~8KB JS + ~300 行 CSS**，零图片/音频资产
  （对比：Lottie 方案 ≥250KB，视频方案 MB 级）——热更 zip 增量可忽略
- Android WebView：shader 为 mediump 精度单 pass，弱 GPU 可跑；不可用即走 CSS 兜底
- 铁律八边界：组件是纯 DOM/canvas，**不触碰任何 Capacitor 插件代理**，无 thenable 风险
