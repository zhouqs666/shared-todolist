01 · BEFORE / AFTER

改版前后对比

上一版「有爱」走的是大众化的「情头+emoji+渐变光斑」路线，在 2024 年的同类情侣 App 中辨识度趋零。 新版把它收回到「信纸 + 火漆 + 印章 + 烫金」的编辑美学里——所有视觉都从「设计令牌」出发，避免再走视觉拼贴的老路。

「少女粉 + emoji 雨」

  • 底色 #fff3f4 偏冷白
  • 大量 emoji ❤💕🌹

  • 慢半拍 280–1200ms 动效

02 · GOALS × STRATEGIES

设计目标 × 核心策略

3 个设计目标

  • 现代化：走出 2018 风格的「emoji 雨」，进入 2026 的「编辑暖意」调性。
  • 简洁：用米杏底 + 留白呼吸，让每一行字都有被珍视的感觉。
  • 品牌一致：从 logo 到阴影，所有元素都从同一套设计令牌派生，杜绝视觉拼贴。

5 个核心策略

05 · KEY SCREENS

关键界面视觉改版方案

01 · 登录页

旧：纯白底 + 大 ❤️ 心形 + 单调表单。新：米杏底 + 双心交错呼吸 + 配对码 / 手机号双入口 + Touch ID。

02 · 主界面

  • Hero 区块：从硬编码数字改为「在一起 N 天」+ 倒计时，蒙德里安式卡片而非「横幅广告」。
  • 角色条：每张待办卡顶部 4px 圆角色条 — 小宝宝 rose-500 / 大宝贝 ink-500 / 隐藏款 legendary。
  • FAB：从「点击弹面板」改为「长按 400ms 展开 4 个花瓣方向的心意菜单」。

03 · 纪念日面板

从「日期宫格」改为「在一起 N 天烫金打戳 + 3 个倒计时行 + 留一句心里话入口」。整体奶油色卡片 + 顶部跳动双心。

04 · 心里话写信 / 阅读

  • 米杏信纸 + 28px 间距横线纹理（仿纸）。
  • 顶部双心交错 logo + 「亲爱的，___」开头 + 「永远爱你的，___」结尾 + 「小 宝 贝」印章。
  • 阅读页带反应 pill（心动 / 收藏 / 已读）和「往昔 12 封」下拉。

05 · 贴纸图鉴

  • 12 格分 3 档（rare 粉 / epic 紫 / legendary 金）。
  • 已解锁：彩色 + 名称 + 解锁日期 +「NEW」角标。
  • 未解锁：灰色剪影 + 「???」+ 提示语（"还没遇见"/"那天还没到"）。
  • 顶部三色拼接进度条 + shimmer 动效。

09 · DESIGN DECISIONS

设计决策记录

DECISION #1 · 双栏布局
如何处理「双主角对称」？
移动端坚持单列纵深 + 双主角镜像，而非死板的 35/30/35 三栏。 iPhone SE 单栏仅剩 ~85pt，无法承载「头像 + 心里话」单元； 拇指热区模型下中间 30% 共享待办会被拇指根部遮挡。 双主角对称改为身份徽章 + 卡片角色条：小宝宝 = rose-500 桃形 16×16；大宝贝 = ink-500 方印 16×16。
DECISION #2 · 暗色模式
首期是否做暗色模式？
不做实现，只备命名。--color-bg-dark / --color-text-dark 已预留， 方便未来扩展。首期聚焦在「暖奢呼吸感」的日间体验。
DECISION #3 · FAB 交互
FAB 是「点击」还是「长按」？
长按 400ms 展开 4 片花瓣菜单（写信 / 留语音 / 拍照 / 共享此刻）。 短按保留为「添加一条新待办」的快速路径。 让 FAB 同时承担「添加」与「心意菜单」双重语义。
DECISION #4 · 主色降饱和
为什么从 #e11d48 降到 #c2410c？
高饱和 #e11d48 在小尺寸 UI（tag / 边框 / 角色条）下会「震」眼睛， 降到 #c2410c 后保留玫瑰色相但让 5% 点缀的克制哲学成立。 主色仅在 CTA / FAB / 强调文本 / 关键图标四处出现，其余走 stone 中性色。
DECISION #5 · 字体策略
为什么用霞鹜文楷？
手写感 × 宋体骨架，最契合「克制浪漫」调性。 衬线字体让心里话、信件、签名这类长文场景获得「书写感」； Inter 兜底英文与 UI，Berkeley Mono 用于倒计时数字。 三个字体不混写在一个 font-family 里，永远先中文后英文。
DECISION #6 · 圆角上限
按钮为什么不做 pill 全圆？
圆角上限 12px（信纸卷角感），不做 pill。 全圆按钮虽然「亲切」，但丧失了「卡片 / 信封 / 印章」的语义。 只有 --radius-full 留给圆形 Avatar 与心形徽章。
DECISION #7 · 动效慢半拍
为什么 280ms 而非 180ms？
符合「从容、被珍视」的调性。 Material 默认 200–300ms、Apple HIG 200–500ms， 我们取中位 280ms 基准 + 480ms 慢节奏 + 720–1200ms 仪式。 速度变慢 = 用户感知到「我们为你留出时间」。
DECISION #8 · 阴影暖色染色
为什么阴影用 rgba(194,65,12)？
阴影统一用玫瑰色染色，禁止冷灰阴影。 冷灰阴影在暖色基底上「脏」且突兀； 暖玫瑰染色阴影与米杏底色融合，让悬浮更有「纸片轻盈」感。 所有阴影色都从 --color-primary-rgb: 194, 65, 12 派生。
